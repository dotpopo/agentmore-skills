# STE 风格写作要点

ASD-STE100（Simplified Technical English）是最初为航空维修文档设计的受控英语规范，分两部分：写作规则（约 9 节）和词典（约 900 个核准词，每词一种词性、一个意思）。它的价值在于用严格的限制逼出清晰的写法，读者很难读错。

## 默认严格度

默认采用"约 80% 严格度"：保留短句、一词一义、主动语态，但允许句式有些变化，让文字不那么像说明书。

- 安全相关、步骤类、需要零歧义的内容，接近 100%。
- 一般性解释，约 80%。
- 用户可以直接指定，例如"用 80% 的 STE 程度解释"。
- "80%"表示宽松程度，不是可以测量的合规分数。

## 合规声明

只有在能核对适用版本、词典和完整规则时，才能说"符合 ASD-STE100"。否则一律称为"STE 风格"。中文等非英语输出只借鉴原则，不声称通过了正式合规检查。

## 规则

| 规则 | 做法 |
|---|---|
| 结论先行 | 先用一到三句说核心结论，再展开 |
| 短句 | 一句话集中表达一个主要意思 |
| 术语一致 | 同一概念全文同一个词；首次出现时解释 |
| 主动语态 | 明确谁执行动作 |
| 单一指令 | 操作句通常只含一个指令，不同动作分开写 |
| 明确指代 | 避免"它""这个""上述内容"指向不明 |
| 区分内容 | 把事实、假设、推断、示例和限制分开写 |
| 保留精度 | 不为简化而删掉否定条件、风险、单位或适用范围 |
| 控制段落 | 一个段落一个主题，不反复复述结论 |
| 警告在前 | 先说"不要做什么"，再说原因 |
| 复杂内容竖排 | 用列表，不把五件事塞进一个长句 |

原规范的英文参考上限：步骤类句子不超过 20 词，描述类句子不超过 25 词，段落不超过 6 句，名词串不超过 3 词。不要把词数限制机械套用到中文，中文可参考每句尽量不超过 30 字。

## 示例

原文：
> 在启动操作之前，操作员应确保液压油箱已经被充满。

STE 风格：
> 先确认液压油箱是满的。然后开始操作。

原文：
> 该系统利用多层缓存来显著降低数据库查询的平均延迟时间。

STE 风格：
> 系统有多层缓存。缓存保存常用数据。查询先找缓存，找不到才查数据库。所以查询更快。
